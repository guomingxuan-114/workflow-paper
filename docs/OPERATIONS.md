# 操作说明

## 直接启动

1. 在桌面双击“流程稿纸 - 打开”。
2. 程序会在后台启动本地服务，并自动打开默认浏览器。
3. 使用完成后，可双击“流程稿纸 - 关闭服务”。

不需要打开 PowerShell，也不会保留可见的终端窗口。开发调试模式支持源码热更新，浏览器刷新即可加载最新界面。

## 从空白开始

1. 欢迎页点击“新建空白”。
2. 在画布空白处右键，选择步骤、判断、里程碑、结束或备注；也可直接按 `Tab` 新建普通步骤。
3. 双击节点或按 `E` 编辑标题与描述。
4. 从节点整圈边框按下并拖到空白处，创建并连接后继节点。
5. 从任意节点边框拖到另一节点任意位置，建立以“拖动起点 → 松手落点”为方向的关系。
6. 点击连线，在右侧详情栏输入关系标签。

画布移动方式：

- 在空白处按住鼠标左键拖动：平移画布。
- 按住 `Shift` 后拖动：框选多个节点。
- 鼠标滚轮：缩放画布。
- 鼠标中键或右键拖动：也可以平移画布。

界面主题：

- 点击顶栏太阳/月亮按钮切换浅色与深色模式。
- 主题保存在文档 `display.theme`，旧文件默认按浅色打开。
- PDF 导出固定采用浅色纸张版式，不受编辑器深色模式影响。

## 分组与大纲

- 选择多个节点后按 `G`，或使用工具栏“建分组”。
- 点击分组标题左侧箭头折叠/展开。
- 拖动分组标题区域会移动分组及成员位置，不改变成员关系和节点内容。
- 同一源节点自然从同一侧离开的多个出口共享主干和计算分叉点；不同侧出口独立离开。右键分叉点可集中编辑该 source 的全部出口条件。
- 左侧大纲与画布共享选择。点击大纲节点会选中画布节点；大纲标题编辑会写回同一节点。

## 保存与恢复

- 首次保存会要求输入文件名；本地宿主以原子替换写入 `documents/`。
- 已命名且位于本地宿主时，空闲约 2 秒会自动保存；保存摘要显示在标题下方。
- 浏览器静态部署会下载文件，不提供任意路径原子覆盖。
- 未保存编辑会缓存到 IndexedDB。异常关闭后重新打开会出现恢复入口。
- 关闭或刷新仍有未保存修改的页面时，浏览器会显示离开确认。

## 导入与版本对比

1. 工具栏点击“导入”。
2. 选择符合 v1 协议的 JSON，或使用内置示例。
3. 导入会创建仍可键鼠编辑的本地文档，并保留每个节点的来源。
4. 点击“版本对比”选择第二个导入快照。比较视图同时展示节点、关系和分组的新增、删除与修改，不自动合并。

## 导出 PDF

1. 点击右上角“导出 PDF”。
2. 新窗口加载总览页和各分组详情页。
3. 在系统打印窗口选择打印机“另存为 PDF”，开启背景图形。
4. 纸张建议 A4 纵向。总览页尊重分组折叠状态；分支源节点生成出口条件页；分组详情页保留全部节点标题、描述、标签和来源。

PDF 是阅读输出。需要继续编辑时请保存并重新打开 `.wflow`。
