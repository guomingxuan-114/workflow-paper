# 操作说明

## 直接启动

1. 双击桌面“流程稿纸 - 打开”。
2. 程序在后台启动本地服务并打开浏览器。
3. 使用完成后双击“流程稿纸 - 关闭服务”。

不需要打开 PowerShell。开发调试支持热更新；修改源码后在浏览器刷新即可。更完整的开发、打包和 Git 说明见根目录 `README.md`。

## 新建与内容编辑

1. 欢迎页点击“新建空白”。
2. 在画布空白处右键，选择节点、判断、里程碑、结束或备注；也可按 `Tab` / `N` 新建普通节点。
3. 双击节点标题或按 `E` / `Enter` 编辑标题与描述。
4. 在右侧详情栏编辑类型、标签、来源、里程碑和重要属性。

第一个节点默认是普通节点，标题为“未命名节点”。开始/结束由用户在详情栏或右键菜单显式设置，类型不限制任何连接方向。

## 画布导航与选择

- 在空白处按住左键拖动：平移画布。
- 按住 `Shift` 后拖动：框选。
- 鼠标滚轮：缩放。
- 鼠标中键或右键拖动：也可平移画布。
- `Ctrl/Cmd + A`：选择全部节点、关系和分组。
- `Delete` / `Backspace`：删除选择。
- `Ctrl/Cmd + Z`：撤销；`Ctrl/Cmd + Shift + Z` 或 `Ctrl + Y`：重做。
- `Ctrl/Cmd + 0`：缩放至适应画布。

平移、缩放只更新浏览视口，不会把文档标成未保存；内容、节点尺寸或布局变化仍会提示未保存。

## 节点形状与缩放

- 节点：约 12px 弧角矩形，内部类型仍为 `task`。
- 判断：椭圆。
- 开始/结束：视觉权重更高的胶囊形。
- 备注：便签形。
- 分叉点：紧凑跑道形，默认宽度约 44px，与旧版计数圆点尺寸相近；标题可为空，空标题时显示当前出边数量。
- 里程碑与重要是独立强调字段，不改变基础形状。

里程碑和重要节点使用当前 palette 的淡色背景填充，同时保留图标、编号或描边，不依赖单一颜色识别。

判断节点只显示标题；描述、标签和来源在右侧详情栏编辑。所有节点内部都不出现滚动条，普通节点标题最多显示两行并在超出时正确省略，椭圆和胶囊标题限制在内接安全区域。

选中节点后，在右侧详情栏输入宽度和高度。尺寸按 10px 网格吸附，并受各形状最小尺寸约束；节点本身不再常驻显示 `NodeResizer` 框和进度条。

修改节点类型时，若此前未改变默认尺寸，会自动切换为新类型默认尺寸；若已经手动设置尺寸，则保留用户尺寸。新建判断与修改得到的判断使用同一套椭圆尺寸模型。

## 分叉点

- 普通节点无论拖出多少条线，都不会自动归并、生成共享主干或自动创建分叉点。
- 可在画布空白处右键选择“新建分叉点”，或从左键拖拽线段产生的断点得到分叉点。
- 新分叉点标题默认为空，标题输入框提示“填写分叉点名称”；空标题时跑道内显示出边数量。
- 填写标题后显示标题，并将出边数量保留在标题旁的小徽标中。
- 从分叉点边框拖出可创建新后继普通节点，或连接已有节点；每条分支线直接以该分叉点为 source。
- 分叉点可选中编辑标题和类型，也可通过普通删除快捷键删除。
- 类型下拉可把分叉点改为节点、判断、开始、结束或备注。
- 不提供分叉点专属右键条件编辑，也不通过双击或键盘打开内容弹窗。

节点底部只显示标签 chips；不同标签自动使用当前 palette 的不同浅色底和边框。无标签时显示“添加标签”，仍可在详情栏编辑。节点内部 ID 和“未标记”占位已移除。

拖动节点时，节点位置由 React Flow 本地更新，边路径通过 `requestAnimationFrame` 只刷新以该节点为 source 或 target 的关系；未受影响的节点和边对象复用。分组内节点使用父组绝对布局补齐坐标，完整质量与自适应简化预览继续按已有阈值切换。

单线是一条从 source 边界到 target 边界的连续三次贝塞尔曲线。分叉点的每条分支也独立从分叉点边界出发；普通节点的多条出边不会汇成共享主干。正向、反向、垂直、斜向、预览和 PDF 共用同一套几何规则。

## 连接关系

节点整条边框都是连接命中区，没有固定 source/target 圆点。

1. 从节点边框按下，表示以该节点为 source。
2. 拖到另一个节点任意位置并松手，建立“起点节点 → 落点节点”关系。
3. 拖到空白处松手，自动创建普通后继节点并连线。
4. 从 B 拖到 A 会建立 B → A，箭头指向 A。
5. 禁止自连和重复同向关系。

节点内部按下用于选择和拖动位置，不触发连接。拖动过程中显示连续预览线和目标轮廓。

## 分支束与线中操作

- 从普通节点边框拖到空白或已有节点：创建一条独立新边；同一节点有多条出边时也为每条线独立绘制。
- 左键拖拽任意已有线段：先取按下位置到原路径的最近投影，在该位置新建“分叉点”，松手后把原边拆成两段。
- 拖到已有节点时建立“分叉点 → 已有节点”；拖到空白时在落点新建普通“未命名节点”并建立派生关系。
- 分叉点等于新派生的起点；其后拖出的所有分支直接来自该分叉点。
- 原边两端位于同一分组时，新建的分叉点和普通节点进入该分组。
- 拖线产生的新节点和三条关系合并为一个撤销 checkpoint，一次撤销全部回退。
- 右键线段的“插入节点”仍是独立命令：仅在点击位置新增一个“未命名节点”并拆分原边，不执行派生连线。
- 点击与拖动按 8px 位移阈值区分；点击线段选择关系，拖动线段执行插入。
- 页面不再提供共享主干或束标签入口；旧 `bundles` 仅作为兼容数据读取。
- 右键连线：选择“插入节点”；默认在点击位置拆分，标签继承规则不变。
- 原线标签会留在包含原文字锚点的一段，另一段为空。若无法判断锚点位置，默认保留在 source 段。

旧文件中的 `bundles` 元数据继续保留以维持格式兼容，但不再参与线条归并或自动生成分叉对象。旧圆形计数按钮不再显示。

右侧详情栏采用即时/短防抖映射：标题、描述、标签、里程碑文字、连线标签和分组名在输入时更新；宽高输入约 100ms 后按网格吸附应用，无效数值回落当前有效尺寸。一个连续输入字段只产生一个撤销 checkpoint，一次撤销即可回退整段输入。

## 分组

- 选择节点后按 `G`、点击工具栏“建分组”，或右键选择“从选择创建分组”。
- 分组使用大圆角弧形框，可折叠。
- 拖动分组标题区域会同步移动全部成员节点和嵌套子组；保存重开后位置不回弹。
- 普通拖动节点只改变位置，不改变归属。
- 节点拖到分组框外仍显示所属分组标记。
- 按住 `Alt` 拖出节点，或在详情栏点击“移出”，才会改变语义归属。

## 大纲、分类与强调

- `Ctrl/Cmd + Shift + O` 或顶栏标签切换画布与大纲。
- 画布和大纲共享节点 ID、标题和选择；大纲可直接改标题。
- 左侧“重要的”分类汇总重要节点、重要关系和重要分组。
- 左侧“里程碑”分类汇总所有里程碑节点。
- 点击分类项会定位并选中画布对象。
- 节点、关系和分组均可在详情栏或工具栏批量标记重要。

备注节点参与的关系自动显示为虚线、中性色、无箭头。

## 配色与界面主题

顶栏太阳/月亮按钮切换浅色与深色界面。浅色/深色属于编辑器展示主题 `display.theme`。

顶栏“配色方案”切换：

- 安静稿纸：默认配色，保持原有视觉。
- 构成主义 · 蓝红黄（包豪斯灵感）：高辨识度参考主题。

配色属于 `display.palette`，随工作流保存，并同时覆盖画布、节点、判断、开始/结束、里程碑、重要、备注、边、分支、束标签、文字与 PDF。来源和完整色值见 [THEMES.md](THEMES.md)。

## 保存与恢复

- `Ctrl/Cmd + S` 保存；`Ctrl/Cmd + Shift + S` 另存为。
- 本地宿主以临时文件、落盘同步和原子替换写入 `documents/`。
- 已命名文件空闲约 2 秒自动保存。
- 未保存修改会写入 IndexedDB 恢复草稿。
- 未命名文件也能恢复为草稿。
- 异常退出后下次启动会显示恢复入口。
- 关闭或刷新仍有未保存修改的页面时，浏览器会显示离开确认。

浏览器静态部署不支持任意路径原子覆盖，会退化为下载文件。

## 导入与版本对比

1. 点击“导入”，选择符合 `workflow-import` v1 的 JSON。
2. 导入节点由来源 ID 和原始节点 ID 派生稳定 ID，并保留来源、版本和提交。
3. 导入结果可继续键鼠编辑。
4. “版本对比”读取第二个导入快照，展示节点、关系、分组的增删改。
5. 关系比较包括 source/target、标签、重要和 `bundleId`；分组比较包括标题、折叠、颜色、成员、父组和重要。

导入协议 schema 和示例位于 `examples/`。

## 导出 PDF

1. 点击“导出 PDF”。
2. 新窗口加载总览、分支条件、分组详情和未分组节点页。
3. 在系统打印窗口选择“另存为 PDF”并开启背景图形。
4. 推荐 A4 纵向。

PDF 使用矢量文字、矢量边和系统中文字体。总览尊重分组折叠状态；折叠成员仍在详情页列出并标注“已折叠”。普通节点的多条出边分别绘制，分叉点的分支从分叉点边界发出，备注线无箭头。大型工作流按分组和节点数分页，不会把全部内容无限缩小到单页。

PDF 是阅读输出；继续编辑请保存并重新打开 `.wflow`。
