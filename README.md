# 流程稿纸

一款本地优先、可嵌入开发工具的可视化工作流文档编辑器。初版提供宿主无关的 TypeScript 编辑器核心、轻量浏览器外壳和本地原子保存服务。

当前版本：`0.2.3`。工作流文档仍使用 schema `2`；旧版 schema `1` 文件可直接打开并自动迁移。

## 直接使用（不用终端）

- 桌面双击 **“流程稿纸 - 打开”**：后台启动本地服务并自动打开浏览器。
- 桌面双击 **“流程稿纸 - 关闭服务”**：停止后台服务。
- 也可以直接双击项目根目录的 `流程稿纸.exe`。

启动器使用开发源码和热更新模式，无需看到终端。修改源码后，在已打开的浏览器中刷新即可调试。

## 运行

要求 Node.js 20 或更高版本。

```powershell
pnpm install
pnpm dev
```

打开 `http://127.0.0.1:4173`。开发模式同时启用本地宿主接口，保存的工作流进入仓库下 `documents/` 目录。

生产运行：

```powershell
pnpm build
pnpm start
```

`pnpm dev` 与 `pnpm start` 均只监听 `127.0.0.1`，无需账号或网络服务。也可以把 `dist/` 放入任意静态 WebView；此时文件保存会退化为浏览器下载，草稿恢复继续使用 IndexedDB。

## 初版能力

- 空白画布、右键建点、节点内容编辑和详情面板。
- 节点整圈边框都是连接起点；不显示固定连接圆点，拖动起点决定 source，落点节点决定 target。
- 从节点连接点拖到空白处创建后继节点，拖到已有节点建立关系。
- 点击连线编辑关系标签；节点拖动仅修改布局。
- 普通节点边框拖出的每条关系都保持独立；不会因为同一节点有多条出边而自动并入共享主干或生成分叉点。
- 右键已有线段仍执行“插入节点”，在点击位置把 `A → B` 拆成 `A → 新节点 → B`。
- 左键拖拽已有线段执行“断线派生”：在原路径最近投影处创建“分叉点”，拆成 `A → 分叉点 → B`，再从分叉点向已有节点或鼠标落点的新节点建立派生关系。整个操作一次撤销。
- 分叉点的多条出边直接以分叉点为起点；分叉关系只能从分叉点边界继续拖出。
- 右键连线也可在线段点击位置插入节点，并根据原标签锚点决定由哪一段继承文字。
- 框选、多选、复制粘贴、删除、撤销重做、缩放和平移。
- 判断为椭圆，普通节点为约 12px 弧角矩形，开始/结束为胶囊形，备注为便签形。
- “分叉点”是持久化节点类型，使用紧凑跑道形；标题为空时显示当前出边数量，填写标题后保留计数徽标。
- 从分叉点边框拖线可创建新后继节点或连接已有节点；所有分支线直接从分叉点边界发出。
- 判断节点只显示标题；其他信息在详情栏编辑，所有节点禁用内部滚动。
- 里程碑和重要节点从当前 palette 取得淡色背景，同时保留图标或编号标记。
- 节点尺寸在详情栏输入，保留 10px 网格吸附和形状最小尺寸，不再显示常驻缩放手柄。
- 切换节点类型时，未手动缩放的节点采用新形状默认尺寸；手动尺寸不会被覆盖。
- 节点底部使用 palette 标签 chips，不再显示内部 ID 或“未标记”占位；无标签时显示“添加标签”。
- 将所选节点组成可折叠分组；分组使用弧形框，拖动分组会同步成员和嵌套子组位置。
- 普通拖动节点不会改变分组归属；拖出后仍显示归属标记，按住 `Alt` 拖出或点击详情栏“移出”才会解除归属。
- 画布与结构化大纲双向选择、标题同步和大纲编辑。
- 左侧可集中查看“重要的”和“里程碑”分类；重要可作用于节点、关系和分组。
- 备注相关连线使用虚线、中性色、无箭头，仍可选择和删除。
- 自动缓存未保存编辑；异常退出后可恢复草稿。
- `.wflow` ZIP 单文件容器；本地外壳采用临时文件、落盘同步与原子替换。
- 导入协议 v1 的结构化程序版本 JSON，并保留源 ID、版本和提交信息。
- 两个导入快照的节点、关系与分组差异对比。
- 分页 PDF 打印文档：总览页、分组详情页、图例、版本和页码，文字及连线为矢量。
- PDF 尊重分组折叠状态，并为分支源节点生成出口条件表。
- 单线与分叉点的每条分支线均使用连续三次贝塞尔曲线；目标在右侧的上/下方向会自然向上或向下收弯，画布、预览和 PDF 共用同一路由。
- 右侧详情栏的标题、尺寸、描述、标签、里程碑文字、连线标签和分组名输入会即时映射到画布，防抖尺寸仍保持 10px 吸附。
- 窄窗口抽屉式侧栏，为后续 IDE WebView 预留小尺寸布局。
- 顶栏可切换浅色/深色界面，并可在“安静稿纸”和“构成主义 · 蓝红黄（包豪斯灵感）”配色间切换；配色随工作流保存，PDF 同步采用。

## 快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Tab` / `N` | 新建节点；有选中节点时自动连接 |
| `E` / `Enter` | 编辑选中节点 |
| `Delete` | 删除选择 |
| `Ctrl/Cmd + C` / `V` | 复制与粘贴节点及内部关系 |
| `Ctrl/Cmd + A` | 选择全部节点、关系和分组 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` / `Ctrl + Y` | 重做 |
| `Ctrl/Cmd + S` | 保存 |
| `Ctrl/Cmd + F` | 查找节点 |
| `Ctrl/Cmd + Shift + O` | 切换画布与大纲 |
| `Ctrl/Cmd + 0` | 缩放至适应画布 |
| `G` | 将所选节点创建为分组 |

鼠标操作：左键拖动空白处平移画布；右键空白画布选择节点类型；拖动节点内部调整位置；从普通节点边框拖出的每条关系保持独立；左键拖动线段会在路径投影处创建分叉点并派生新线；从分叉点边框可继续拖出独立分支；右键线段执行插入节点；点击连线选择关系；拖动分组标题区域移动分组及成员；`Shift + 拖动`框选，`Alt + 拖动`将节点显式移出分组。

拖动节点时只更新该节点和受影响边的实时路径，不重建文档节点数组；完整质量与自适应简化预览仍在同一拖动会话中切换，简化预览也保持平滑曲线。侧向连线使用克制的三次贝塞尔曲线，目标在源节点上方时向上收，在下方时向下收。

## PDF

点击“导出 PDF”会打开打印预览。请在系统打印对话框中选择“另存为 PDF”。文档使用系统中文字体栈（微软雅黑、苹方、Noto CJK），文字保持可检索，连线是 SVG 矢量路径。大型工作流按分组和每页节点上限分页。

直接保存时请选择“另存为 PDF”；产品不会把 PDF 当作可编辑源文件。

PDF 总览尊重折叠分组；详情页仍列出已折叠成员并标注“已折叠”。普通节点的多条出边分别绘制，分叉点的分支从分叉点本身发出；备注线无箭头。配色方案与画布一致。

交互、配色和 PDF 验收截图位于 [output/screenshots](output/screenshots)，包括整边框连接、反向连接、垂直连接、独立分支线、分叉点、线中插入节点、里程碑/重要、备注虚线、分组弧形框、两套配色和 PDF 总览。主题来源与色值见 [docs/THEMES.md](docs/THEMES.md)。

## 架构

```text
src/core/         文档模型、校验、导入、差异、容器编解码
src/core/edgeRouting.ts  画布与 PDF 共用的方向、边界触点和曲线路径
src/persistence/  IndexedDB 恢复草稿
src/host/         打开、保存、打印和宿主上下文适配边界
src/components/   React 编辑器 UI 与 React Flow 空间交互
src/pdf/          可打印的 HTML/SVG 文档生成
scripts/          本地宿主、原子文件写入和示例生成
e2e/              Playwright 浏览器验收
```

文档语义（`nodes`、`edges`、`groups`、`bundles`）与布局（`layout`）是分开的字段。节点形状与里程碑/重要强调分开存储；分叉点作为独立 `fork` 节点保存；拖动、缩放、折叠不会改写节点标题、描述、关系或来源。旧 `bundles` 数据继续兼容读取，但不用于合并画布线条。`.wflow` 格式和 v1 → v2 迁移详见 [docs/FILE_FORMAT.md](docs/FILE_FORMAT.md)。

产品名、扩展名、MIME、版本和草稿库名统一位于根目录 [product.config.json](product.config.json)，前端、本地宿主和示例生成器共同读取该配置。

## 技术选型

- TypeScript + React + Vite：宿主无关、启动快、可嵌入 WebView。
- `@xyflow/react`（React Flow，MIT）：成熟的节点、端口、缩放、框选和连线交互；图形层可替换，文档模型不依赖它。
- `fflate`（MIT）：体积小、同步 ZIP 编解码，容器内容仍是可校验 JSON。
- `lucide-react`（ISC）：轻量线性图标，不引入品牌资产。
- IndexedDB：浏览器本地异步草稿缓存，不需要后端。
- Node 本地宿主：提供可验证的同目录临时文件加原子替换；浏览器静态部署则回退为下载。

## 已知限制

- PDF 依赖用户系统中文字体；不存在中文字体的极简环境需要安装 Noto Sans CJK。
- 浏览器静态部署无法提供任意路径的原子覆盖，只提供下载；原子保存由本地宿主实现。
- 分组当前以节点列表归组，一个节点只进入一个直接分组；跨组语义关系仍通过边表达。
- 拖线自动继承分组仅在原边两端属于同一直接分组时生效；两端分属不同分组时，C、D 不自动迁移到任一侧。
- 大纲可编辑标题、选择和分组折叠，但不提供拖放重排语义边。
- 版本对比基于同一导入来源的稳定节点 ID，不推断跨来源的节点重命名。
- 分叉条件暂存在边标签中，不引入执行语义；改变 source/target 仍需删除后重连。
- 平移和缩放会随后续保存写入视口，但视口本身不触发未保存状态、草稿或自动保存。
- 自动降级按实际帧耗时触发：单帧超过 18 ms 连续 3 次后进入简化直线预览，冷却 1500 ms；手势结束后 1500 ms 恢复完整渲染。
- 旧版束标签不再生成共享主干或圆形计数按钮；节点旁的 React Flow Handle 保持隐藏。
- 当前没有节点内联拖拽缩放手柄；尺寸统一在右侧详情栏输入。
