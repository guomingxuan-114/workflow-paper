# 无终端启动器

`WorkflowLauncher.cs` 编译为仓库根目录的 `流程稿纸.exe`。双击后：

1. 检测 `http://127.0.0.1:4173/api/status` 返回的应用版本。
2. 若服务未运行、旧版未返回版本或版本与 `product.config.json` 不一致，先关闭旧服务。
3. 查找本机 Node.js，以隐藏窗口启动当前工作区的开发外壳。
4. 等待当前版本服务就绪后，以带构建参数的 URL 打开默认浏览器。
5. 传入 `--shutdown` 时，通过本地 API 关闭服务。

桌面快捷方式由构建者创建；源码更新后无需重新编译启动器，除非启动逻辑本身发生变化。
